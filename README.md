**不收錄 2022 年 Remastered 專屬內容。**

## 直接使用

- 網站首頁：`index.html`，手機/桌機可輸入**繁體中文或日文原名**搜尋，並使用上方分類。
- 離線使用：下載 GitHub ZIP 解壓縮後，直接開啟 `index.html`；攻略資料已內嵌，不需要連線；外部來源連結須連線。
- 線上 PWA：`manifest.webmanifest` + `sw.js`；須由 HTTPS／GitHub Pages 提供才可正常快取。
- 資料結構：`data.json` 供後續維護；更新後由維護者執行 `sync_site.py` 同步到離線 HTML（一般使用者不需操作程式）。
