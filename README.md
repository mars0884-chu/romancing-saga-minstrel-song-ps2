# 《復活邪神：吟遊詩人之歌》v0.4.9｜離線圖文快取

正式網站：https://mars0884-chu.github.io/romancing-saga-minstrel-song-ps2/

## 本次
- 每筆文字、日文原名、任務條件、逐層寶箱、已核實點位保存在內嵌資料中，網站使用 Service Worker 完整離線提供文字。
- 「儲存離線圖文」會逐張**嘗試**將 73 個外部圖片網址存進本機瀏覽器的 CacheStorage，記錄成功與失敗數量；失敗圖片不虛報可離線。
- Service Worker 會攔截已在本機快取的外部遊戲原圖，斷網後載入同一張圖，主角／裝備／迷宮／區域圖都可在圖資真正儲存成功後離線開啟。
- 新增瀏覽器程式自動測試：模擬外部圖片伺服器回應後關閉網路，再檢查實際迷宮圖片的 naturalWidth > 0。測試採固定模擬圖，**不是**真實第三方圖站連線驗收。
- 撤掉2幅「系統」自繪示意圖，不再充當真實遊戲圖。
- 原站原圖像素約300×300，放大至800%仍不能補出不存在的細節；需要實際高解析實機畫面才能提高真正解析度。

## 使用與限制
1. 用桌機或 iPhone Edge 開網站，連網時按「儲存離線圖文」。看到「圖片已保存 73/73」才代表該瀏覽器完整圖片快取，隨後可斷網使用；網站在首次開啟時一定需要網路。
2. 第三方可禁止跨站讀圖；無法保證每張都能成功載入，頁面會報告準確數字。刪掉瀏覽器資料也會刪除圖檔快取。
3. GitHub repo ZIP **只能保證離線文字、網站程式和已有合法本機圖示**，不能聲稱包含所有原圖。沒有得到權利人完整授權，不把第三方攻略地圖與玩家照片重新打包到公開 ZIP。
4. 極限攻略頁面註明「無断転載はご遠慮下さい」，Square Enix 日文遊戲畫面分享指引亦有限制，不能直接把第三方圖作為公開永久下載素材。
5. 主角的五章是完整周目導覽，不等於逐場戰鬥、逐任務全面核對完成。八主角序章、65任務仍有資料細度不一；手機實機未驗。
6. 本專案目前仍以2005 PS2原版為底，Remastered獨有要素需要另行研究，不能宣稱Remastered 100%完工。
