## 完整圖文攻略的驗收原則
沒有固定幾步就算完成。每個任務逐一核對：觸發條件、期限、角色差異、地點入口、分層路線、寶箱（固定／隨機／再生）、機關、頭目招式與推薦配置、關聯任務、報酬、返回路線及失敗條件。五步或十步都是內容長度，不能當作完成率。

## 仍待追查與限制
- 不是所有迷宮都取得高解析原始地圖，珊瑚海完整高清圖尤其仍未確認；部分地圖為站內示意，不得冒充實際遊戲畫面。
- 第三方攻略圖留在來源站，由瀏覽器在本機個人快取；外站拒絕快取、跨域回應或 iOS 容量限制時，可能無法完全離線。**不能將「快取成功」等於「iPhone Edge 實際斷網每張都可顯示」。**
- 角色、裝備、村莊圖片及所有時限分歧持續補齊，不會把只有條目數的卡片認定為完成。
- 現有 PS2 金手指與 Remastered 的平台差異尚未全面實機驗證。
