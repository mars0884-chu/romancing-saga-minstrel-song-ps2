# 《復活邪神：吟遊詩人之歌 Remastered》PWA v0.9.7｜開啟即查詢攻略

**正式網址：** https://mars0884-chu.github.io/romancing-saga-minstrel-song-ps2/

## 使用方式
開啟網站即可搜尋繁體中文／日文攻略、打開任務與迷宮圖並放大閱讀。**不需要 ZIP，也沒有任何匯入動作。**
首次連線開站時，PWA 會預存攻略資料、站內圖檔並在背景嘗試保存第三方真實圖片。只要沒有受外站或裝置容量限制，之後斷網仍可查看已快取的內容；失敗圖片顯示缺圖，不冒充已全部離線。

## 驗收原則
攻略沒有固定「五步」上限，也不靠計數判定完成。真正完整的任務應包含前置、時限、角色差異、出入口、逐層路線、機關、固定／隨機寶箱、頭目招式和配置、獎勵、回程、任務間關聯與失敗條件；無公開依據時標待核對。
