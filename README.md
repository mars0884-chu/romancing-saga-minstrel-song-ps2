## 網站功能
- 桌機與手機直式／橫式響應式介面；繁中／日文全文、樓層、寶箱與機關搜尋。
- 11 區域索引，22 筆城鎮／村莊，53 筆主要迷宮與6筆重點路線補充；有可放大原圖與樓層寶箱條件。
- 八位開場主角與五位 Remastered 新增可入隊角色；任務及較完整深度攻略之間新增「接續閱讀完整攻略」導覽、返回上一層和瀏覽器上一頁。
- 金手指按分類收藏，保留PS2與Remastered平台差異警告；金手指未經實機測試。
- PWA 主程式及文字首次連線後可離線搜尋；圖片需在該裝置按「儲存離線圖文」嘗試快取，可顯示尚未儲存的圖片，**不可把網址數當作成功的離線圖數**。
