# 2005 PS2《ロマンシング サガ -ミンストレルソング-》攻略

版本：v0.4.6（目前最新版）。繁體中文／日文雙語搜尋、離線 PWA。**只收錄 2005 PlayStation 2 版**，不收 2022 Remastered 追加功能。

正式 App： https://mars0884-chu.github.io/romancing-saga-minstrel-song-ps2/

## 本次新增

- 新增 **20 筆新手注意事項**，包含開局、早期易失敗任務、事件進度、LP/BP、逃跑／連鎖戰、地圖技能、存檔、法術、職業、同伴與版本差異。
- 攻略總數 232 筆，站內完整內文可離線搜尋。
- 原本 21 張地區／事件／迷宮圖**都明確標成示意圖**，不是遊戲內真實地形圖；地區分類稱為「區域索引」。
- 外部來源僅作查證，不依賴外部網站才能看攻略。
- 含來源原網址及失效、版本差異註記，資料由不同來源交叉整理，不轉貼原文。
