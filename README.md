# 復活邪神：吟遊詩人之歌 — 2005 PS2 原版攻略

**版本：v0.2.0-ps2-research-preview（2026-10-15）**

這是獨立的 **2005 PlayStation 2**《ロマンシング サガ -ミンストレルソング-》繁體中文攻略資料包，不收錄 2022《Remastered》新內容。

## 使用方式

1. 使用 GitHub Pages，或下載儲存庫 ZIP 解壓縮後直接開啟 `index.html`。桌機 Edge / Chrome 可離線查詢、日文原名搜尋、分類搜尋、複製 PS2 金手指。iPhone Edge 可開啟靜態 HTML，但取決於 iOS 對本機檔案與解壓縮方式的支援；**未經真機驗證**。
2. 若部署在支援 HTTPS 的靜態網站（如 GitHub Pages），`manifest.webmanifest` 與 `sw.js` 可供加到主畫面及離線快取。
3. 攻略內容已內嵌 `index.html`，**不需連線、伺服器或讀取 JSON**；`data.json` 是方便後續更新的結構化來源；修改資料後需以隨附同步工具重建 HTML 的內嵌內容。
4. 首頁先顯示 24 筆結果，可搜尋、切分類或按「顯示更多結果」。外部出處連結需要網際網路，且部分巴哈與舊站會阻擋或失效。

## 主要內容

- 主角 8 名：繁體中文、日本原名及出身簡述。
- 任務 61 條（其中部分仍待逐條完整流程核實）＋11區地圖＋53個迷宮／探索地點研究索引：重點路線與內部進度條件（避免誤解 PS2 遊戲會顯示百分比）。
- 系統 10 條、資料庫入口及原版裝備 21 條、PS2 金手指 10 組、來源導覽卡 15 筆。
- 研究來源 **83 個頁面／連結**（含需核實的索引），涵蓋巴哈精華區及站外日文、英文、簡體中文來源，狀態與取得限制見 `RESEARCH.md`。
- 此為第一批可追溯來源的摘要，**不是 89 件事件已全部獨立校對，更不是『公開來源已挖盡』**。

## 不含內容

- 2022 Remastered 五名新可加入角色、追加任務、追加頭目、倍速、便利功能、道具、職業及完整 NEW GAME+ 系統。
- 將巴哈、GameFAQs、攻略網站文章或地圖整篇複製到本站；僅提供原創摘要與出處。
- 未驗證任務「假啟動」金手指；只收錄有確切文字碼、明確日本 PS2 `SLPM-65920` 來源的 10 項。

## 金手指重要提醒

`SLPM-65920` 對應本次找到的日本 PS2 代碼，**不是**各國版本通用；來源作者對 AR2、XP V4 的格式描述不確定，未做實際 PS2／模擬器測試。先備份原始存檔，切勿一次啟用全部碼。特別注意「戰鬥次數固定」可能破壞劇情時間點。

## 研究／著作權

- `data.json` 包含來源 URL、標題及來源的取得狀態，方便後續專案維護。
- `RESEARCH.md` 記錄已核對、待核對、失效、僅歷史引用、無法直接取得等分級。
- `assets/icon.svg` 是為本網站全新製作的**PS2 時期色彩意象圖示**，不是原版官方封面圖。原版封面仍應在取得合法使用權後置換，不自動盜用購物網站圖片。
- **2026-10-15 依使用者最新指示上傳第一批研究預覽版**；後續巴哈站內、外部連結與其他網路資料持續追查，集中驗證後再發布新版本。不修改其他專案。
