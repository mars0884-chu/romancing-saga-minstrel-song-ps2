## 直接使用（不必前往其他網站）

**正式入口：https://mars0884-chu.github.io/romancing-saga-minstrel-song-ps2/**

1. 第一次上線時開啟攻略，按「儲存離線攻略」，等到看到「已儲存」才關閉網路。
2. 用 iPhone／桌機的「加入主畫面／安裝」建立 App 捷徑；以後從主畫面直接開啟。
3. 不需要點原始攻略網站：搜尋、任務步驟、迷宮寶箱、日文名稱、金手指全在 `index.html`，無第三方 JS 或網路 API。
4. 點「資料來源」是內部離線存檔：僅顯示出處的名稱、狀態和網址文字，不會跳出 App。

**注意：首次安裝或重新下載仍需網路；手動清除網站資料、移除 App 或系統清除快取可能造成離線內容被刪除。** 這不表示必須常態連網使用。iPhone Edge 真機離線保留時間仍須實測。
