# 復活邪神：吟遊詩人之歌｜2005 年 PS2 原版攻略

**v0.4.1（2026-10-16）**｜僅限 2005 PS2《ロマンシング サガ -ミンストレルソング-》（SLPM-65920）。**排除 2022 年 Remastered 專屬要素**。

## 開啟網站與離線使用

正式網址：https://mars0884-chu.github.io/romancing-saga-minstrel-song-ps2/

首次請在有網路時開啟此網址；靜待頁面載入完成，從 Edge／Safari 的分享選單使用「加入主畫面」或電腦 Edge 的安裝 App。完成第一次快取後，可以中斷網路，從主畫面圖示直接打開，搜尋已完整內嵌的繁中、日文攻略。

搜尋與攻略本體全部在 `index.html` 中，無需外部 API；**出處外站連結本身仍需要網路**。iPhone Edge 具體加入主畫面的操作與離線行為須在真機確認。

## 資料及維護

`data.json` 為原始資料；`index.html` 已內嵌可離線查詢的資料；`sw.js` 提供網站快取；`manifest.webmanifest` 提供可安裝設定。使用者不需碰 HTML、命令列或 JSON。

本次保留之前所有既有資料，補入里高島財寶洞穴、恐龍蛋勝利數、托馬艾火山、魔之島、叢林探索及相關寶箱／地圖技能；資料存在來源狀態、錯誤與版本差異仍須交叉核對。2005 原版封面圖像的著作權屬 Square Enix，本站僅用於遊戲攻略辨識。
