# 復活邪神：吟遊詩人之歌｜2005 PS2 原版攻略

**目前版次：v0.4.0（2026-10-16）**；由 v0.3.0 連續更新，不跳號。

僅整理 2005 年日版 PlayStation 2《ロマンシング サガ -ミンストレルソング-》（SLPM-65920），不加入 2022 Remastered 新增角色、任務、功能或金手指。

## 開始使用

- 網頁：開啟 `index.html`；可用**繁體中文與日文原名**搜尋、分類切換、展開任務及迷宮步驟。
- 離線：下載儲存庫 ZIP、解壓縮後開啟 `index.html`。資料已內嵌，不需要讀取外部 JSON。
- GitHub Pages／PWA：倉庫有 `manifest.webmanifest`、`sw.js` 和圖示；但是否已啟用公開 Pages 仍需另外驗證。
- 一般使用者**不需要修改 HTML、JSON 或執行任何程式**。

### 必須知道的限制

53 座迷宮的原始地圖索引尚**未逐座完整驗證所有樓層及寶箱**；部分巴哈原頁回傳 403 或舊站失效；金手指是 2005 年日版歷史碼，**未經 PS2 實機驗證**。模擬手機尺寸測試不等同 iPhone Edge 真機驗收。

資料不複製原始攻略全文、版權地圖或遊戲封面；網站圖示為自製 PS2 原版風格圖示。
